##  THÔNG TIN MÔN HỌC
- **Môn học:** Phát triển Ứng dụng Web
- **Trường:** Đại học Kinh tế TP.HCM (UEH)
- **Chủ đề:** Website Tin tức Game
- **Năm học:** 2025-2026

---

##   MÔ TẢ ĐỒ ÁN
Dự án thiết kế website tin tức game tập trung xây dựng một trang web cung cấp thông tin và bài viết về game với giao diện hiện đại, thân thiện người dùng. Website được thiết kế responsive, dễ sử dụng và đáp ứng nhu cầu cập nhật tin tức game nhanh chóng cho người dùng.

---

## 🛠️ CÔNG NGHỆ SỬ DỤNG

### Frontend
- **HTML5, CSS3, JavaScript**
- **Bootstrap 5** 
- **jQuery** - AJAX calls
- **Font Awesome** - Icons
- **TinyMCE/CKEditor** - Rich text editor

### Backend
- **PHP 8.x**  (OOP + MVC)
- **PDO** - Database abstraction
- **Composer** - Dependency manager (optional)

### Database
- **MySQL 8.0** 
- **Stored Procedures** - Business logic
- **Triggers** - Auto update data
- **Views** - Complex queries

### Tools & Services
- **Git/GitHub**  - Version control
- **Microsoft Teams/Trello**  - Task management
- **Shared Hosting**  - For database access
- **Postman** - API testing
- **VS Code** - IDE
